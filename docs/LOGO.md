# Cavity QED MD logo

The emblem combines a bent H2O molecule, opposing optical cavity mirrors and a
standing-wave motif. It identifies the software; it is a visual mark rather than
a quantitative field or molecular-structure diagram.

## Assets

| File | Intended use |
|---|---|
| [cavity-qed-md-logo.png](assets/cavity-qed-md-logo.png) | Horizontal wordmark for light backgrounds, websites and release announcements |
| [cavity-qed-md-icon.png](assets/cavity-qed-md-icon.png) | Compact emblem for README headers, browser icons and software avatars |

Both PNG files have transparent backgrounds. Keep the proportions and allow
clear space around the mark. The compact emblem is used in the repository README
so that the project title follows GitHub's light or dark text theme. The full
wordmark is used on the website's light background.

The visual palette follows the website: forest ink, teal, turquoise and a coral
oxygen accent. The software name is **Cavity QED MD**; the repository remains
`cavity-qed-md`.

## Creation

Created with the built-in Image Generation tool on 30 October 2026. The original
logo was generated with the following prompt; the icon was derived from it with
the second prompt. These assets do not change the scientific model or release
validation status. Software licensing and upstream notices remain documented
in [LICENSES.md](../LICENSES.md).

### Wordmark prompt

> Use case: logo-brand. Create one polished, professional logo for the scientific open-source software named exactly "Cavity QED MD". Asset type: a horizontal transparent PNG logo lockup suitable for the top of a GitHub README and a research-software website. No other text or tagline. Icon on the left, clean highly legible wordmark on the right in a modern understated geometric sans-serif. Design the icon as a minimal, distinctive emblem combining a correct bent three-atom H2O molecule (one larger oxygen joined to exactly two smaller hydrogens, about 105 degrees bond angle) with two opposing vertical optical cavity mirror strokes and one restrained sinusoidal standing-wave line. Keep exactly three atom discs; no atom labels. Use flat vector-like shapes with crisp edges and consistent generous stroke weight. Color palette coordinated with an existing cream-and-teal scientific website: deep forest ink #172e2f, rich teal #136b62, muted turquoise, a small warm coral oxygen accent. Hydrogen discs must remain visible on both light and dark backgrounds, with an outline if necessary. Icon should remain recognizable at small sizes. Wordmark must be exact: "Cavity QED MD" on one line in dark forest ink. Balanced horizontal composition, generous but not excessive transparent margins, no border, no backdrop, no gradients, no 3D, no shadows, no gloss, no mockup, no watermark, no planetary orbit or atomic electron-orbit imagery. Deliver only the finished logo on true transparency.

### Icon prompt

> Edit target: supplied Cavity QED MD logo. Produce a square, icon-only version for the software avatar and website icon. Remove the wordmark and its entire empty horizontal area; preserve exactly the water molecule between the two teal optical cavity mirrors and its standing-wave line. Keep one coral oxygen and exactly two light hydrogens, same molecular geometry and colors, same mirror shape, same waves, same icon design. Recenter this existing emblem on a square canvas, occupying about 85 percent of the canvas with modest even transparent margins. Genuinely transparent background. No lettering, no background, no added graphics. Match the supplied emblem closely; do not redesign.
