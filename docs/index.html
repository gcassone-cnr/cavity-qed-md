01 / The method

A shared configuration.
Consistent energy and forces.

At every configuration, eT relaxes the electronic state for fixed nuclear and photon coordinates. The interface returns the energy and forces to i-PI for the next propagation or sampling step.

01   ELECTRONIC STRUCTURE

eT evaluates the surface

Fixed-displacement QED-HF with the recovered nuclear-gradient patch. The matching eT source snapshot and upstream license are included.

02   FORCE INTERFACE

The client connects both sectors

Nuclear forces and the photon derivative travel through ordinary ffsocket. SCF continuation, cold fallback and rolling scratch support repeated calls.

03   STATISTICAL MECHANICS

i-PI advances R and q

Classical NVT/NVE examples, one-bead Eckart NVE and a separate joint nuclear–photon PIMD example provide explicit starting points.

Read the coordinate and Hamiltonian conventions

The final pseudo-particle L stores q in its x coordinate, with mass 1 in atomic units. Its transverse coordinates stay zero. The client maps q to the coherent displacement z = q√(ω/2). The photon harmonic energy is already included in the electronic result. Full method and interpretation notes ↗

02 / Get started

Build the matching
electronic engine.

Install prerequisites, extract one archive, then build and validate. The installer automatically applies the complete v4 gradient correction and generates eT’s Fortran sources before CMake. No manual repair patches are needed.

  • PlatformUbuntu 22.04 / 24.04 · CPU
  • Python3.10–3.12
  • Sampling enginei-PI 3.2.0
  • Integral librarylibcint 6.1.2
1 · Extract the ZIP or website source archive

Save the download in ~/Downloads and choose one extraction method. These commands create a new source tree, separate from the installed executable.

ZIP download
unzip "$HOME/Downloads/cavity-qed-md-final.zip" \
  -d "$HOME/cavity-qed-v4"
cd "$HOME/cavity-qed-v4/cavity-qed-md"

For this website’s source tar.gz download, use:

tar.gz download
mkdir -p "$HOME/cavity-qed-v4"
tar -xzf "$HOME/Downloads/cavity-qed-md-source.tar.gz" \
  -C "$HOME/cavity-qed-v4"
cd "$HOME/cavity-qed-v4/cavity-qed-md"

# System prerequisites

# Validate the installed electronic executable

Internet access is required for dependencies. Use a fresh extraction directory and installation prefix. Wait for installation to succeed before activation; require the force-suite PASS before MD. Source env.sh in each new terminal. For repeated checks or runs, choose new output names.

03 / Explore the workflows

Start small. Check each layer.

Executable examples and analysis tools are shipped with the source. The short inputs exercise the software; scientific observables require separate convergence tests.

H₂O + 1 modeNVE · 100 steps

A monomer smoke test

Generate a 10 fs input and run the recovered analytic CBO-HF workflow. Each launch checks nuclear and photon forces before starting dynamics.

This workflow uses laboratory-z polarization, ω = 0.0187505 a.u., λ = 0.01 a.u. and tight cc-pVDZ by default. Treat these as example parameters.
