01 / The method

Energy, forces and propagation

At every configuration, eT relaxes the electronic state for fixed nuclear and photon coordinates. The interface returns the energy and forces to i-PI for the next propagation or sampling step.

01   ELECTRONIC STRUCTURE

eT evaluates the surface

eT evaluates the fixed-displacement QED-HF energy, analytic nuclear gradient and molecular dipole.

02   FORCE INTERFACE

The client returns energies and forces

The client sends the energy and nuclear and photon forces through i-PI’s ffsocket. It reuses converged SCF orbitals and retries failed warm starts from a fresh guess.

03   STATISTICAL MECHANICS

i-PI advances R and q

i-PI runs classical NVT and NVE dynamics, one-bead global Eckart NVE, and joint nuclear–photon path-integral sampling.

Read the coordinate and Hamiltonian conventions

The final pseudo-particle L stores q in its x coordinate, with mass 1 in atomic units. Its transverse coordinates stay zero. The client maps q to the coherent displacement z = q√(ω/2). The photon harmonic energy is already included in the electronic result. Full method and interpretation notes

02 / Get started

Install and validate

Download and extract the source archive. The installer builds the patched eT executable, installs i-PI and stages the simulation workflows.

  • PlatformUbuntu 22.04 / 24.04 · CPU
  • Python3.10–3.12
  • Sampling enginei-PI 3.2.0
  • Integral librarylibcint 6.1.2
1 · Extract the source archive

Save the source archive in ~/Downloads and extract it into a new directory.

Source archive
mkdir -p "$HOME/cavity-qed-v4"
tar -xzf "$HOME/Downloads/cavity-qed-md-source.tar.gz" \
  -C "$HOME/cavity-qed-v4"
cd "$HOME/cavity-qed-v4/cavity-qed-md"
Complete installation and troubleshooting
2 · prerequisites / 3 · build / 4 · validate
# System prerequisites
sudo apt update
sudo apt install -y build-essential gfortran git patch unzip \
  pkg-config python3 python3-venv python3-dev \
  libopenblas-pthread-dev liblapack-dev

# Build the CBO-HF workflow
sha256sum -c SHA256SUMS
BUILD_JOBS=8 WITH_DFT=0 bash install.sh \
  "$HOME/opt/et-ipi-v4"
source "$HOME/opt/et-ipi-v4/env.sh"
cd "$HOME/opt/et-ipi-v4/workflow"

# Validate the installed electronic executable
python3 compare_backends.py
python3 validate_forces.py --all-nuclear \
  --output force_validation_v4

Internet access is required for dependencies. Use a fresh extraction directory and installation prefix. Activate the environment after installation and confirm the force suite passes before running dynamics. Source env.sh in each new terminal and choose a fresh output name for each run.

03 / Explore the workflows

Simulation and analysis examples

Run a water monomer with classical or path-integral sampling, then use the analysis tools to inspect the trajectories. Converge simulation settings before collecting production observables.

H₂O + 1 modeNVE · 100 steps

Classical dynamics of a water monomer

Run a 10 fs CBO-HF NVE example. The launcher checks selected nuclear and photon forces before propagation.

This workflow uses laboratory-z polarization, ω = 0.0187505 a.u., λ = 0.01 a.u. and tight cc-pVDZ by default. Treat these as example parameters.

Nuclei + photon8 beads · PILE-L

Joint quantum sampling

The bundled monomer example replicates the nuclei and q over eight beads. PILE-L uses local Langevin thermostatting for each active centroid degree of freedom, including q, with a 25 fs thermostat time.

This example uses y polarization, ω = 0.01666 a.u., λ = 0.005 a.u. and aug-cc-pVDZ. Match parameters before comparing it with the MD example. PIMD thermostat trajectories are not physical real-time spectra.

bash / from the extracted source root
source "$HOME/opt/et-ipi-v4/env.sh"
cd examples/monomer-pimd
python3 -m unittest discover -s tests -v

# Run one copy at a time because the socket name is fixed.
IPI_INPUT=ipi_cbo_pimd.xml \
ET_CLIENTS=8 ET_THREADS=1 \
bash run.sh

Inspect the trajectory

Tools cover dipole-based IR, photon-coordinate spectra, replica averaging, peak plots, energy drift and force-evaluation throughput.

Use the actual output filenames and sample interval: timestep × output stride. A photon peak alone does not establish an avoided crossing or a converged polaritonic spectrum.

bash / installed workflow directory
# Inspect available options before analyzing your run

04 / Validation

Validation and scientific scope

Check the compiled eT executable against finite differences of the relaxed energy before starting dynamics. The monomer suite covers all nine nuclear force components and the photon force.

CheckCoverage
Electronic forcesAnalytic and finite-difference forces at zero and finite coupling for two photon displacements.
Interface and restartDriver parsing, force payloads, SCF restart and fallback, and i-PI integration with harmonic test forces.
Source and buildeT source generation, patch application and SHA-256 checks of the distribution.

The workflows cover finite molecular systems on a single-mode CBO-HF surface. Production simulations require convergence of the electronic model, timestep and sampling. Path-integral calculations also require bead convergence. Validation procedures
